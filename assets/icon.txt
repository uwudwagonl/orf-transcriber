Place an `icon.ico` file here (256x256 multi-resolution) before building.

If absent, the build still works — PyInstaller and WiX both handle the
missing icon gracefully (the .exe and Add/Remove Programs entry just use
default Windows icons).

A quick option: take any PNG, run it through https://icoconvert.com/
or `magick convert input.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico`.
